Number of Factors/Components
==========================

This analysis helps to decide how many factors (exploratory factor analysis) or components (principal component analysis) to retain. It combines several commonly used methods in one place: parallel analysis, the eigenvalue criterion, and Velicer's minimum average partial (MAP) test. The methods do not always agree, and no single method is definitive; it is good practice to consider them together with the interpretability of the solution. The number you decide on is entered manually in the Exploratory Factor Analysis or Principal Component Analysis.

### Assignment Box
-------
- Variables: the variables to base the decision on. Scale, ordinal, and nominal variables are allowed.
- Data: either raw data (observations in rows, variables in columns) or a variance-covariance matrix. For a variance-covariance matrix the sample size is required.

### Summary table
-------
The table shows the number of factors/components suggested by each method side by side: the parallel analysis, the eigenvalue criterion, and Velicer's MAP. A suggestion of 0 means that no factors/components are suggested for retention.

### Parallel Analysis
-------
Parallel analysis (Horn, 1965) compares the eigenvalues of the data with the eigenvalues of random data without any structure. A factor/component is suggested for retention as long as its eigenvalue is larger than the 95th percentile of the eigenvalues of the random data. For raw data, the random data are generated by resampling each variable independently; if only a correlation matrix is available (variance-covariance input or polychoric/tetrachoric correlations), normally distributed random data are simulated.
- Eigenvalues based on: whether the parallel analysis is based on the eigenvalues of principal components or of factors. The principal component-based version is a common choice also when the goal is to determine the number of factors for a factor analysis.
- Number of iterations: the number of random datasets that are generated (default: 20). The 95th percentile becomes more stable with more iterations.
- Set seed: the random data are generated with a random number generator; setting a seed makes the results reproducible.

### Eigenvalue Criterion
-------
- Eigenvalues above: factors/components with an eigenvalue above this value are suggested for retention. The default of 1 corresponds to the Kaiser criterion (Kaiser, 1960). The eigenvalues are principal component eigenvalues if the parallel analysis is based on principal components, and factor eigenvalues if it is based on factors.

### Velicer's Minimum Average Partial (MAP) test
-------
Velicer's MAP test (Velicer, 1976) partials the first 0, 1, 2, ... principal components out of the correlation matrix and computes the average squared partial correlation of the remaining variables. As long as the components capture systematic variance this average decreases; once components start to capture only unsystematic variance it increases again. The number of components with the lowest average squared partial correlation is suggested for retention, which can be 0 if the original correlations are already smaller than any of the partial correlations. The test is always based on principal components, independent of the parallel analysis setting. The suggestion is always shown in the summary table.

### Base Analysis on
-------
- Correlation matrix: the Pearson correlation matrix of the data.
- Polychoric/tetrachoric correlation matrix: appropriate for ordinal variables. Only available for raw data with ordinal or nominal variables. This is sometimes unstable when the sample size is small and when some variables do not contain all response categories.

### Output
-------
- Parallel analysis table: the eigenvalues of the real data and the mean eigenvalues of the random data. Factors/components suggested for retention are marked with an asterisk.
- MAP table: the average squared partial correlation after partialling out 0, 1, 2, ... principal components. The suggested number of components is marked with an asterisk.
- Scree plot: the eigenvalues plotted against the number of factors/components. The horizontal line marks the eigenvalue threshold. Optionally, the mean eigenvalues of the random data from the parallel analysis are added.

### Missing Values
-------
- Exclude cases pairwise: the correlations are computed from all available pairs of observations.
- Exclude cases listwise: only cases without any missing value in the selected variables are used.
